Detailed Description

A 3x3 Tic-Tac-Toe variant using numbers.

Player 1 uses odd numbers (1,3,5,7,9), Player 2 uses even numbers (2,4,6,8). Winning condition: Sum of 3 numbers in a line equals 15.
